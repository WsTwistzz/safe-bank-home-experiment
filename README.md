## 这份稿子是什么

同一个首页的五种视觉做法并排对比，**内容完全一致**（总资产 26,000.00、7 天待扣 ¥45.00、三笔交易），只改视觉与摆放：

| 列 | 方向 | 要点 |
| --- | --- | --- |
| 基准 | 现有首页 | 硬分割线分区，小安在 Tabbar 中央凸起 + 右下悬浮球 |
| A | 灵动岛 + 小组件 | 顶部状态栏做成灵动岛胶囊；内容拆成独立小组件卡 |
| B1 | 实心蓝圆盘 | 白色通栏 + 平滑下凹缺口 + 中央 50px 品牌蓝实心圆盘 |
| B2 | 品牌蓝圆钮 | 与 B1 同结构，中央圆钮质感不同 |
| C | 黑白灰卡片 | 参考图的黑白灰、大圆角白卡、双列快捷操作 |

## 反馈
